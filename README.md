Порівняльний аналіз швидкодії доступу до БД (C++)
Даний проєкт реалізований на мові C++ для оцінки ефективності обробки запитів до СУБД MySQL. Дослідження порівнює два підходи: прямі запити (Raw SQL) через MySQL Connector та використання ORM-технології (ODB).

Структура проєкту (C++)  
/speedRaw — модуль, що використовує MySQL Connector/C++ для виконання прямих SQL-запитів.  

/speedOrm — модуль, реалізований за допомогою ODB (C++ Object-Relational Mapping).  

transportcomppany.sql — файл для ініціалізації структури бази даних (3НФ).  

Підготовка до запуску  
1. База даних:   
*Встановіть MySQL Server.    
*Імпортуйте структуру таблиць з файлу transportcomppany.sql.  

2. Середовище та залежності:  
*Для роботи проєкту в Visual Studio необхідно підключити зовнішні бібліотеки:   
*Для speedRaw: Встановіть MySQL Connector/C++.  
*Для speedOrm: Встановіть бібліотеку ODB.

Запуск тестування  
1. Тест прямих запитів (Raw SQL):  
Перейдіть у папку speedRaw, відкрийте проект у Visual Studio, скомпілюйте (Build) та запустіть файл .exe.  
Опис модуля: Модуль реалізований за допомогою низькорівневого драйвера MySQL Connector/C++. Це забезпечує пряму взаємодію з БД без зайвих прошарків, що дає максимальну швидкість.

Робота з меню:  

Пункт 1 (SELECT test): вимагає введення LIMIT та автоматично тестує всі сутності (клієнти, водії, замовлення тощо).  
Пункт 2 (JOIN test): вимірює швидкість складного запиту по 6 таблицях одночасно (INNER, LEFT, RIGHT JOIN).  
Пункт 3 (CRUD test): виконує цикл INSERT -> UPDATE -> DELETE (рекомендовано для таблиці orders).  

2. Тест ORM (ODB):  
Перейдіть у папку speedOrm та запустіть скомпільований модуль.  
Опис модуля: Реалізовано за допомогою бібліотеки ODB, яка дозволяє мапити класи C++ на таблиці SQL. Це спрощує розробку, але додає певні витрати на трансформацію об'єктів.  

Генерація коду підтримки ODB  
Перед компіляцією проєкту необхідно згенерувати C++ файли для мапінгу класів на таблиці бази даних. Для цього використовується компілятор ODB. Виконайте наступні команди в терміналі (у папці з заголовними файлами):  

    odb --std c++11 -d mysql --generate-query client.hxx
    odb --std c++11 -d mysql --generate-query driver.hxx
    odb --std c++11 -d mysql --generate-query vehicle.hxx
    odb --std c++11 -d mysql --generate-query order.hxx
    odb --std c++11 -d mysql --generate-query tripdetails.hxx
    odb --std c++11 -d mysql --generate-query triplog.hxx

Інструкція користувача: При запуску з'явиться меню вибору операцій:  
Пункт 1 (Average SELECT): Тестування швидкості вибірки. Програма запитає LIMIT (кількість записів) та Repeats (кількість повторів). Розраховується середній час завантаження об'єктів для всіх моделей бази даних.  
Пункт 2 (Insert Test): Замір часу на створення нових об'єктів у таблиці Order. Користувач вказує кількість повторів, після чого програма вираховує середній час операції.  
Пункт 3 (Update Test): Тестування швидкості оновлення існуючих даних. Вимірюється час зміни полів об'єкта та синхронізації з БД.  
Пункт 4 (Delete Test): Замір швидкості видалення об'єктів.
